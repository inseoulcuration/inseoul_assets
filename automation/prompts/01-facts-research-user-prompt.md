# 사실조사 프롬프트 (facts research)

- 사용처: `n8n-workflows/01-batch-submit.json` → Code 노드 `사실조사 요청 본문 생성`
- role: `user` (system 프롬프트 없음)
- model: `claude-sonnet-4-6` / max_tokens: 8000
- tools: `web_search_20250305` (max_uses 6)

⚠️ 이 프롬프트는 원본 Make HTTP body 업로드가 없어서, 인계 문서(inseoul______0920.md) §5-1의
마크다운 본문에서 재구성했습니다. 다른 두 프롬프트(KR 원고·EN 원고)는 실제 Make body
JSON 파일을 그대로 파싱해 옮겼지만, 이것만은 실제 Make 시나리오(HTTP 4)의 Body와
한 번 대조 확인하시길 권합니다.

`__TOPIC__` `__PILLAR__` `__TYPE__` `__DIRECTION__` `__FRESHNESS__` 는 시트의
주제/필러/유형/한줄요약/신선도 값으로 치환됩니다.

```
당신은 리테일·공간 콘텐츠의 사실조사를 담당합니다.

주제: __TOPIC__
필러: __PILLAR__
유형: __TYPE__
방향: __DIRECTION__
신선도: __FRESHNESS__

조사 규칙
1. 주제에 등장한 모든 대상(지명·브랜드·시설)을 각각 따로 검색해 검증하세요. 필요한 만큼 검색을 쓰되, 주제와 무관한 대상으로 범위를 넓히지는 마세요.
2. 방향에 적힌 논점을 뒷받침하거나 반박하는 자료를 우선합니다.
3. 서로 다른 매체 2곳 이상에서 확인하세요. 공식 발표·보도가 블로그보다 우선입니다.
4. 신선도에 연도가 있으면 그 시점의 자료를 찾으세요. 오래된 자료로 대체하지 마세요.
5. 추정·전망·업계 관측은 넣지 마세요. 확인된 것만.
6. 자료를 못 찾은 대상은 fact_ids를 빈 배열로 두세요. 억지로 채우지 마세요.
7. 검색 중간에 요약이나 설명을 쓰지 마세요. 검색을 모두 마친 뒤 최종 JSON만 한 번에 출력하세요.

출력은 반드시 <<< 와 >>> 사이에 JSON만. 그 밖에는 아무것도 쓰지 마세요.

<<<
{"topic":"","entities":[{"name":"대상","fact_ids":["f1"]}],"facts":[{"id":"f1","claim":"검증된 사실 한 문장","source_idx":0,"source_date":"YYYY-MM-DD","type":"보도|공식|관찰","confidence":"high|medium"}],"numbers":[{"value":"표기 그대로","meaning":"","fact_id":"f1"}],"names":["고유명사 정확한 표기"],"angle":"리테일 MD 시선에서 가장 흥미로운 지점 한 줄. 공백 포함 45자 이내","sources":[{"title":"","url":"","publisher":"","date":"YYYY-MM-DD"}],"image_grade":"A|B|C","grade_reason":""}
>>>

facts는 6~8개, 각 한 문장으로 간결하게.

numbers에는 facts의 claim 문장 안에 실제로 등장하는 숫자·시기만 넣으세요. claim에 없는 값을 fact_id와 함께 적는 것은 금지입니다.

names에는 facts의 claim 문장 안에 등장하는 고유명사만 넣으세요. 검색 중 봤지만 claim에 쓰지 않은 이름은 제외합니다.

image_grade는 이 주제의 이미지 저작권 부담을 판정한 값입니다.

A — 개인 사업자, 독립 브랜드, 소규모 편집숍·카페·공방, 개인이 운영하는 팝업.
    권리자가 노출을 반기고 사용 허락을 구하기 쉬운 대상.
B — 중견 브랜드, 백화점·쇼핑몰, 복합문화공간, 프랜차이즈, 공공기관 운영 공간.
    공식 홍보 이미지가 존재하고 보도자료 배포가 이루어지는 대상.
C — 명품 브랜드, 대기업이 직접 운영하는 플래그십, 글로벌 브랜드의 공식 매장,
    이미지 사용에 법무 검토가 붙을 것으로 보이는 대상.

판정 규칙
1. 주제에 여러 대상이 섞여 있으면 가장 높은 부담을 기준으로 판정합니다.
2. 애매하면 한 단계 보수적으로 판정합니다.
3. grade_reason에는 왜 그 등급인지 한 줄로 적습니다. 30자 이내.
```
